# Questions pour des champions

Questions de mathématiques pour le cycle d'orientation (Genève), en mode élève.

Les élèves ouvrent un lien (ou un code QR) préparé par leur enseignant : il donne les exercices choisis.
Sans lien, la page affiche : « Demande le lien à ton enseignant. »

- `index.html` : la dernière version ;
- `AAAA-MM-JJ/` : une version précise (les anciens liens continuent de marcher) ;
- `404.html` : un lien vers une version supprimée ouvre la dernière version.
- `essai/` : version de test, remplacée à chaque essai ; ses liens ne sont pas à donner aux élèves.
