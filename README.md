# Questions pour des champions

Questions de mathématiques pour le cycle d'orientation (Genève), en mode élève.

Les élèves ouvrent un lien (ou un code QR) préparé par leur enseignant : il donne les exercices choisis.
Sans lien, la page affiche : « Demande le lien à ton enseignant. »

- `index.html` : la dernière version ;
- `1/`, `2/`… : une version précise, numérotée par le jour de sa mise en ligne (17.11.2026 = 1, puis 1 de plus chaque jour) ;
- `AAAA-MM-JJ/` : les versions d'avant, nommées par leur date (jusqu'au 17.11.2026) ; les anciens liens continuent de marcher ;
- `404.html` : un lien vers une version supprimée ouvre la dernière version.
- `videos/` : les vidéos ouvertes depuis la page (une seule fois pour toutes les versions ; leurs noms ne changent jamais).

## Autres pages

- `escape-pythagore/` : escape game « L’atelier de Pythagore » (théorème de Pythagore, 11e) ; chaque élève reçoit sa propre version (numéro en bas à droite).
- `castle-defense/` : jeu de défense de château (opérations sur les fractions) ; un joueur, sur ordinateur, à la souris.
- `bataille-de-maths/` : jeu « Bataille de maths » façon Age of War (opérations sur les fractions) ; un joueur, sur ordinateur, à la souris.
